# Maquette : Chalet Althéa

**Ceci n'est pas le site officiel du Chalet Althéa.**

C'est une **maquette de démonstration** réalisée par **OBT Agency** pour présenter un projet de site au
Chalet Althéa, à Samoëns (Haute-Savoie). Le propriétaire n'a pas encore validé ce projet. Le site officiel
reste chalet-althea.fr.

- Les pages portent `noindex, nofollow` : elles ne doivent pas apparaître dans les moteurs de recherche ni
  concurrencer le site ou la fiche Google du chalet.
- Les textes, les tarifs et les photos du chalet viennent de son site public et de la fiche de l'office de tourisme.
- Les photos de Samoëns sont libres de droit (Wikimedia Commons) et créditées dans les mentions légales.
- Le formulaire de contact et le panneau de réservation n'envoient rien : aucune donnée n'est collectée ici.

À la demande du propriétaire, ce dépôt et la page publiée seront retirés immédiatement.

Le contenu est généré depuis les sources du projet : ne rien corriger ici, tout serait écrasé au déploiement
suivant.
